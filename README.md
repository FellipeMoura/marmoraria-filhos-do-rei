# Marmoraria Filhos do Rei

Landing page organizada para edição no VS Code e continuidade com Claude/Copilot.

## Estrutura

- `index.html` — conteúdo e estrutura da página
- `style.css` — todo o visual e responsividade
- `script.js` — animações simples e formulário do WhatsApp
- `assets/` — logo e fotos reais dos projetos

## Como abrir

1. Extraia o ZIP.
2. Abra a pasta no VS Code.
3. Instale a extensão Live Server.
4. Clique com o botão direito em `index.html`.
5. Escolha `Open with Live Server`.
